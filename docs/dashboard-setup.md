# 棚卸ダッシュボード セットアップ手順

全店舗・全月の売上／原価率／棚卸データを閲覧できる社内向けWebアプリ。
データ再取得ボタン（クラウド実行）も内蔵する。

ソース: `gas/dashboard/dashboard.gs`（バックエンド）+ `gas/dashboard/index.html`（画面）

## 1. Apps Script プロジェクトを作る（初回のみ・約10分）

1. https://script.google.com を開く →「新しいプロジェクト」
2. プロジェクト名を「棚卸ダッシュボード」などに変更
3. 最初からある「コード.gs」に `dashboard.gs` の中身を丸ごと貼り付け
4. 左の「ファイル」の「＋」→「HTML」→ 名前を `index` にして
   `index.html` の中身を丸ごと貼り付け
5. 💾 保存

## 2. 公開（デプロイ）

1. 右上「デプロイ」→「新しいデプロイ」
2. 歯車アイコン → 種類「**ウェブアプリ**」
3. 設定:
   - 説明: 任意
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: 社内が Google Workspace なら「**組織内の全員**」、
     そうでなければ「**リンクを知っている全員**」
4. 「デプロイ」→ 初回はGoogleの許可画面が出るので「許可」
5. 表示された **ウェブアプリのURL** を社内に共有（スマホでも開ける）

## 3. 再取得ボタンの初期設定（管理者・1回だけ）

1. https://github.com/settings/personal-access-tokens/new でトークンを作成
   - Repository access: Only select repositories → `amami-cell/-`
   - Permissions > Repository permissions > **Actions: Read and write**
2. ダッシュボード右上「⟳ データ再取得」→ 下部の「初期設定」を開く
   → トークンを貼り付けて「トークンを保存」

## 更新方法

コード（dashboard.gs / index.html）を修正したら、Apps Script に貼り直して
「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→
「デプロイ」。URLは変わらない。

## 画面構成（v2）

共通: 最上部に **フード／ドリンク／FD合算** の表示切替。すべての数値・
在庫回転日数がその区分で再計算される。

- **一覧画面**
  - 在庫回転日数（全社・選択月）をヒーロー表示
    （在庫回転日数 = 棚卸高 ÷ 1日理論原価。1日理論原価 = 月理論原価 ÷ 月日数）
  - 全店舗の棚卸項目表（回転日数・売上・仕入・理論原価・棚卸高・ロス計・不明ロス、並べ替え可）
  - **⟳ FW取込／⟳ インフォマート取込**: 選択月×全店舗の再集計を起動
- **店舗画面**（一覧の行をタップ）
  - 在庫回転日数（最新月）をヒーロー表示
  - 最新月を一番上に、月ごとの棚卸項目ブロックが下へ続く
    （売上・仕入・前月/当月棚卸高・実原価・理論原価・必要/廃棄/不明ロス、売上比つき）
  - 各月ブロックに **⟳ FW取込／⟳ インフォマート取込**（その月を再集計）
  - **ロス入力**: ＋廃棄ロス／＋必要ロス → 区分(F/D)・内容・金額 → 更新で
    「ロス記録」シートに蓄積。明細表示・削除可。不明ロスは
    実原価（前月棚卸＋仕入−当月棚卸）− 理論原価 − 登録ロス で自動計算
